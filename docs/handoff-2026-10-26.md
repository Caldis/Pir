## 已完成的功能与用户裁定

### 原生偏好窗口与品牌

- 四个页签为基础、贴图、更新、关于, 使用 NSTabViewController toolbar 模式和系统选中态
- 公共样式集中于 PreferencesStyle.swift, 整窗 NSVisualEffectView 延伸到标题与工具栏区域
- 页面内容固定高度并锚定顶部安全区域, 切换动画仅改变窗口边框, 背景随整窗覆盖
- 关于页参考 Mos 布局与图标, 名称背后保留浅色单色动态 Logo, 采用大幅局部遮挡构图
- 关于页入口为主页、Github、欢迎使用 Pir、许可证、喂胖大咪. 捐赠弹窗参考 Mos 布局与支付素材
- 官网使用 shader 动态背景, 提供中英文. 品牌大小写统一为 Pir

### 热键与欢迎页

- 默认 Shift + Command + V, 展示采用修饰键组 + 普通键的 keycaps
- 容器按内容自然宽度布局, 上下左留白一致, 右侧可延伸用于对齐. 清除按钮与录制容器对齐
- 基础设置标签为贴上热键, 附作用描述与支持类型的问号 popover
- Carbon RegisterEventHotKey 接收已注册组合键事件, NSEvent local monitor 处理应用窗口内录制, 两者均免辅助功能权限
- 相同快捷键录制仍显示蓝色反馈. 无效单键累计 5 次后显示 Escape 提示, 初始与成功录制后隐藏
- 欢迎页热键区域可点击录制, 外框按 keycaps 自然尺寸加四边 8 pt 留白
- 欢迎页每次触发热键或完成录制均贴出 Logo 并播放烟花. 同一会话复用一张演示贴图, 单面板最多叠加四组粒子
- Vortex 1.0.4 已 vendored, 保留来源与许可. 减少动态效果开启时仅贴 Logo
- Pir 已删除 PermissionFlow 和权限引导文案, 相关授权流程属于 Mos 任务

### 图片、文本与缩放

- 图片列表缩略图具有边框, 提供再次贴上、显示、隐藏、删除和确认后清空全部. 空列表隐藏清空全部
- 空插图采用简化粗线条手绘构图, 提供标题与副标题, 整体上移 10 pt
- 图片外沿 alpha 检测覆盖四条边. 透明图片保留原图透明度与阴影, 悬停时显示圆角虚线边界
- 不透明图片使用现有边框与窗口阴影. 透明窗口截图的异常轮廓曾与系统阴影及圆角组合有关, 具体曲线类型未获运行时证明
- 浮窗悬停显示复制、复原、关闭按钮. 复制位于复原左侧, 按下时放大
- 控制区域阴影为四边渐隐的 140 × 64 pt 区域, 与按钮同步显示, 保持点击穿透
- 缩放命中区域为 6.5 pt, 命中区域与鼠标光标区域一致. 文本子视图转发边缘缩放光标
- 文本支持选择、编辑、撤销、复制当前内容, 修改合并持久化, 空文本可恢复
- 应用原生编辑菜单支持剪切、复制、粘贴、全选、撤销与重做
- 文本顶部 12 pt 留白可拖动, Option + 正文拖动可移动, 边缘支持缩放
- 新建文本按 CoreText 测量, 上限 560 × 420 pt, 同时受屏幕可用区域 55% × 60% 限制. 超过 4096 UTF-16 单元直接采用上限
- 文本最小 120 × 54 pt, 图片最小 120 × 80 pt. 文本采用 TextKit 2 视口布局

### 文件浮窗

- 复制多个文件后贴出原生图标或列表, 支持切换模式、双击默认应用打开、原生文件 URL 拖拽与复制文件引用
- 公开 API 无法直接取得完整 Finder 右键菜单, 用户接受简版仅提供从列表中移除
- 移除引用保留源文件, 最后一项移除后关闭窗口. 最多保留 512 个文件引用
- 文件列表与模式随会话持久化. 当前实现保持简单范围

### 多语言

- 原生英文与简体中文采用系统 .lproj, 交接时为 86 个匹配键, 跟随系统语言
- 官网为 44 个双语键, 默认跟随浏览器语言并支持手动切换
- scripts/check-localizations.py 提供键集合检查
- 临时 AppleLanguages 英文覆盖已删除, 当前跟随系统中文

- 版本采用 X.Y.Z, 构建号 YYYYMMDD.N, 稳定 tag 为版本号, Sparkle 按构建号排序
- 更新包名称为 Pir.Versions.0.1.2-20261026.4.zip. update-feed 使用 prerelease, 稳定版 latest 与 feed 独立
- gh release create 的 --target 使用完整 40 位 SHA, 缩写曾返回 422

- package-lock 的 integrity 可能偶然含旧品牌字节, 全局品牌替换曾破坏依赖哈希. 品牌迁移时保留哈希原值
- Vortex 的标准 SwiftPM 清单需要显式资源声明. 此项已修复
- Popover 关闭动画中旧窗口仍可能存在, 测试直接检查 recorder.popover
- macOS 15 原生按钮存在约 1 pt 光学偏移, 布局测试使用总垂直留白 8 pt 与中心差 ≤ 1 pt
- 所有 UI 交互使用 mcp__cua_repl.js. 新会话先读取工具文档, 再获取新 app/tab 绑定, 原会话 JavaScript 绑定不跨会话
- macOS CUA 的 listWindows 不可用, 应用读取针对所选主窗口. 授权、完整文件拖放等证据边界单独记录
- 构建、签名、公证、公开发行与实际更新分别回读, 状态报告逐项区分
