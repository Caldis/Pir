# Pir 设计与动效约定

本文面向设计实现维护者与后续 agent, 汇总用户已裁定的视觉方向、Mos 参考范围及当前实现入口. 页面尺寸与动画参数以源码为准, 当前发布进度见交接记录

## 视觉方向

Pir 使用原生 macOS 控件、统一毛玻璃背景和双层玻璃品牌形状. 官网采用前卫的程序化抽象视觉, 包含流体渐变、玻璃折射、少量虹彩与细颗粒质感. 正文、操作入口与内容展示保持清晰, 动效承担环境氛围和操作反馈

用户提供的 shaders.com 参考描述包含流体与网格渐变、光学折射、虹彩金属和程序化噪声. 这些是视觉语言参考, 当前官网实际组合为 Swirl、FlutedGlass 与 FilmGrain

状态栏图标采用应用 Logo 双悬浮面板的单色轮廓. 贴屏页保留双方框页签图标, 空态插图组合图片、文字与文件卡片. 快捷键帮助采用 16 pt mini 问号按钮

应用名统一为 Pir. 设计稿、图标来源、界面标题、链接与多语言文案均按当前品牌核对

## 窗口布局与切换

- NSWindow 使用透明标题栏与 fullSizeContentView, NSTabViewController 使用 toolbar 模式
- 全窗口 NSVisualEffectView 覆盖标题栏、页签与内容, material 为 toolTip, blendingMode 为 behindWindow, state 为 followsWindowActiveState
- 页面内容固定高度并锚定顶部安全区域, 窗口调整高度时保持顶部位置
- 整窗背景与页面内容采用各自布局生命周期. 高页切低页时, 背景持续覆盖当前窗口动画区域
- 默认页签内容过渡关闭, 窗口边框采用尺寸动画. 减少动态效果时窗口尺寸直接更新
- 公共间距、文字与控件规格集中于 PreferencesStyle.swift. 单页布局使用共享规格

验收包含高低页签连续往返、错误提示区域出现与消失、页面顶部内容稳定性、背景覆盖以及深浅外观. 静态截图只提供某一帧的证据, 毛玻璃和切换稳定性需要直接观察

## 关于页品牌图形

用户要求在应用名称后方显示浅色单色动态 Pir Logo. 后续裁定采用放大的局部遮挡构图, 底部按钮保留留白

AboutBrandArtwork.swift 使用 CALayer 与 CAShapeLayer 绘制两张玻璃片, 配合缓慢微幅转动和反射扫光. 它属于层动画, 与欢迎页 Metal 动画分别维护. 图形颜色跟随系统外观与增强对比度, 保持装饰层点击穿透

关于页隐藏、窗口遮挡、最小化、应用失活或减少动态效果开启时停止装饰动画. 页面重新出现后按当前状态恢复. 图形及渐隐遮罩限制在名称区域, 底部操作区保持稳定

## 欢迎页与反馈

- 欢迎窗口每次展示按当前屏幕可用区几何居中, 开始按钮采用放大的原生 large 规格, 标签最小尺寸为 168 × 28 pt, 外围保留系统按钮留白
- 首次非登录启动展示欢迎页, 正式版完成入门后常规启动保持静默; debug 本地调试保留偏好设置入口, 登录启动保持静默. 显式重新打开与隐藏菜单栏图标后的启动恢复偏好设置
- 默认快捷键采用 Shift + Command + V, 已保存的用户绑定继续生效
- Logo 出生动效使用 WelcomeArtwork.swift 与 LogoBirth.metal.txt, 纹理来自当前应用图标
- Metal 展示包括轮廓、材质显现与光效, 文字、热键和按钮在独立稳定布局中呈现
- 动画约 4.2 秒后停在最终画面. 遮挡与最小化暂停, 关闭释放回调, 减少动态效果时呈现静帧. Metal 不可用时显示静态应用图标
- 热键区域外框跟随 keycaps 自然尺寸, 四边留白一致. 设置页右侧清除控件与录制容器对齐
- 欢迎页每次触发快捷键均提供 Logo 贴图与烟花反馈, 包括重复快速触发. 同一会话复用演示贴图
- Vortex 烟花在当前屏幕四个区域独立随机取位并朝向屏幕中心, 粒子模板尺寸为 84 pt, 爆炸速度为 0.54、变化量为 0.42, 均为此前参数的三倍
- 烟花使用透明点击穿透面板, 连续触发最多叠加四组, 最后触发后 3.2 秒清理. 关闭欢迎页、屏幕拓扑变化、退出和减少动态效果开启时结束粒子渲染; 减少动态效果时保留 Logo 贴屏反馈

LogoBirthTests 支持通过 PIR_ARTWORK_SNAPSHOT_DIR 导出分阶段 PNG. 验收同时包含最终静帧、减少动态效果、连续热键和窗口关闭后的资源释放

## 浮窗反馈与透明内容

浮窗的复制、复原与关闭按钮在左上角悬停控制区出现, 按压显示放大反馈. 普通内容采用窗内布局, 透明图片采用图像外的独立子面板; 子面板优先位于上方, 屏幕顶部空间不足时显示在下方. 控制区保持屏幕内定位, 关闭时解除父子关系并释放

普通内容控件采用 0.18 秒淡入淡出. 透明图片的控件和虚线边界采用 92% 至 100% 缩放与透明度过渡, 离场采用反向过渡, 减少动态效果时直接切换状态. 快速进出从当前呈现状态衔接, 离场回调按最新悬停状态生效. 图像和外置控制区之间保留短暂移动宽限

透明图片的四条边缘 alpha 参与外观判断, 原图透明度和自带阴影保留. 悬停时显示无阴影圆角虚线矩形边界, 表达浮窗范围与边缘缩放区域. 四边 6.5 pt 输入环使用 alpha 为 1/255 的 evenOdd 填充, 内部透明区域保持原样, 边缘缩放光标与命中范围共用相同尺寸

按钮区域采用左上角径向渐变阴影, 背景使用 10 pt 圆角并裁切. PinControlsBackdrop 的 colors alpha 为 0.55、0.30、0, locations 为 0、0.45、1, startPoint 为 0.28、0.72, endPoint 为 1、0. 渐变与虚线装饰层保持点击穿透

文件浮窗仅显示复原与关闭按钮, 图片与文本的复制图标高度为 13 pt. 文件图标采用 56 pt 尺寸与固定 8 pt 网格间距, 窗口高度按内容行数计算. 文本与文件浮窗复用偏好面板的 toolTip 材质和 behindWindow 混合, 内容层保持透明

图片边缘检测、虚线边界、缩放命中区与原图透明度分别维护

## 文件选择与操作

文件图标与列表使用 Finder 风格选择态. 图标采用图标描边与文件名高亮, 列表采用整行系统高亮. 空白区域拖动支持部分相交框选, Command 切换相交项, Shift 追加相交项

右键菜单提供打开、移到废纸篓、显示简介、重命名、在 Finder 中显示与从列表移除. 重命名弹窗保留原生确认与取消, 多文件名称采用编号并保留扩展名. 操作错误使用原生提示, 废纸篓结果按成功项同步引用, 目录操作同步涉及的后代路径

显示简介打开 Pir 自有的原生 AppKit 元数据窗口, 每个文件各自展示. 系统图标与可复制字段包含名称、种类、大小、位置、日期及权限信息, 长内容支持换行与滚动. 从列表移除继续保留源文件

## 官网 Shader

website/artwork.js 使用 shaders 4.0.5 的 shaders/js 接口, 动态加载 WebGPU 渲染器. 一个 canvas 承担背景氛围, 产品演示、文案与操作入口为普通 HTML

| 层 | 当前作用 |
| --- | --- |
| Swirl | 深蓝、紫、浅青和少量暖粉的缓慢流体渐变 |
| FlutedGlass | 波形玻璃折射、轻微色散与高光 |
| FilmGrain | 静态细颗粒质感 |
| CSS 静态背景 | WebGPU 缺失、减少动态效果、节省流量或渲染失败时的呈现 |

渲染根据视口可见性、标签页可见性、用户暂停、减少动态效果和节省流量状态启停. 离开页面时释放渲染器和观察器, 浏览器前进后退缓存恢复时重读播放状态. 渲染尺寸有分辨率预算, 普通网页布局独立适配屏幕

WebGPU 失败与静态回退属于功能验收范围. 网站构建成功只提供打包证据, 真实 shader 外观、暂停恢复与设备差异需要浏览器验证

## 设计验收清单

1. 同时查看中文与英文, 确认长度变化后的 keycaps、按钮和说明排版
2. 检查深浅外观、增强对比度与减少动态效果
3. 连续切换高低页签, 观察内容顶部、窗口顶部与整窗毛玻璃覆盖
4. 使用白底图片、带透明阴影的 macOS 窗口截图和纯透明边缘图片检查左上控制区、圆角背景、无阴影虚线、进出动画与每条边的缩放命中
5. 检查热键初始、录制、相同组合键成功、无效单键累计、清除与再次录制状态
6. 检查欢迎窗口几何中心、大按钮、Logo 动画的开始、最终静帧、遮挡恢复、随机放大烟花、快速重复触发与关闭释放
7. 检查官网窄屏布局、动态与静态背景、暂停恢复和页面离开后的生命周期
8. 检查文件相交框选、Command 与 Shift 多选、图标与列表选中态、重命名、部分成功废纸篓结果、跨浮窗引用和独立简介窗口

视觉回归记录写明应用版本、构建号、系统版本、外观与辅助显示设置. 截图、运行时观察和代码测试分别说明验证范围
