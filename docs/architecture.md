# Puv 架构

本文面向开发者与后续 agent

## 组件

| 边界 | 职责 |
| --- | --- |
| App 生命周期 | 菜单栏入口、应用重新打开、偏好设置与退出 |
| 剪贴板读取 | 按触发时内容选择图像或文本, 保留文本换行与空白 |
| 面板管理 | 创建独立 NSPanel, 定位、缩放、复原、隐藏、最小尺寸与关闭释放 |
| 会话存储 | 原子元数据写入、内容资产、后台 I/O、关闭删除与退出刷新 |
| 屏幕定位 | 稳定屏幕 UUID、屏幕内相对坐标、断开临时迁移与重连恢复 |
| 快捷键 | Mos 来源录制交互、全局系统注册、冲突处理与偏好持久化 |
| 偏好设置 | 基础设置、贴图管理、更新与关于, ServiceManagement 开机启动状态同步 |
| 首次入门 | Logo 动画、窗口内快捷键录制、Logo 贴屏试用与 Vortex 屏幕烟花 |
| PuvCore | 内容分类、尺寸约束与快捷键等可独立测试的策略 |
| 官网 | 静态产品页、shader 视觉与 GitHub Release 下载 |

## 设计决策

原生 AppKit 提供菜单栏、非激活面板与动态系统颜色, SwiftPM 提供轻量构建和核心行为测试. 系统注册的快捷键直接驱动单次剪贴板读取, 应用空闲时保持事件驱动

每张贴图拥有独立窗口与内容生命周期, 管理页与浮窗关闭采用相同删除路径. 管理页提供隐藏与显示, 会话保存隐藏状态. 清空全部操作在确认后关闭所有可见和隐藏贴图, 并清理保存记录. 图片缩略图使用系统分隔线颜色描边. 悬停工具条提供原始尺寸复原与关闭, 边缘 6.5 pt 区域响应缩放并显示对应方向光标. 用户关闭后清理记录并释放图像和文本. 应用退出保留会话, 重启后恢复. 图片采用 cover 裁剪填满面板, 初始尺寸保留原始图片的逻辑显示尺寸. 文本保留原有换行与缩进, 使用系统背景色与文字色适应明暗主题

会话内容位于 `~/.config/puv/`, 创建贴图时写入内容, 移动与缩放仅更新元数据并合并后台写入. 屏幕归属使用稳定显示器 UUID, 保存屏幕内位置, 临时迁移保留原始归属供重连恢复

文本使用系统 TextKit 2 视口布局, 显式解除默认最小宽度限制, 频繁缩放遵循可见内容布局, 规避全文重复排版

图片创建时从已解析的 CGImage 检查四条 1 px 外沿, alpha 小于 254 时关闭 NSWindow.hasShadow, 表面圆角设为 0. 检查采用边缘条带, 临时空间随边长增长, 缩放期间复用创建时的结果. 原图透明度与自带阴影保持原样, 不透明图片与文本继续使用系统窗口阴影和 10 pt 圆角

浮窗悬停工具条使用白色图标, 右上角 112 × 64 pt 范围内的径向暗色渐变提供局部对比度. 渐变层和按钮随悬停同步显示与隐藏, 渐变视图保持点击穿透. 按钮按下时图标围绕中心放大至 116%, 松开后恢复, 点击区域与布局保持原有尺寸

新建文本窗口采用 CoreText 测量自然尺寸, 最小 120 × 54 pt, 最大 560 × 420 pt, 同时限制为屏幕可用尺寸的 55% × 60%. 测量最多检查 4097 个 UTF-16 单元, 超过 4096 单元时直接使用尺寸上限. 正文保留完整内容并竖向滚动, 会话恢复优先使用已保存窗口尺寸

隐藏菜单图标后的应用重新打开事件负责恢复偏好设置入口. 开机启动状态以 SMAppService 当前状态为准, 注册失败时界面显示实际状态

偏好设置集中在 Sources/Puv/Preferences/, PreferencesStyle 定义公共字体、间距、页高与材质. NSTabViewController 的 toolbar 模式生成系统页签和选中态. 基础与关于使用 AppKit, 贴图列表嵌入 SwiftUI. 各页继承公共 toolTip 毛玻璃根视图, 窗口采用 fullSizeContentView, 背景覆盖整窗与所有页面的最大动画范围, 页面固定高度并锚定顶部安全区域. 页面顶边锚定容器顶部, 窗口尺寸采用 AppKit 实测装饰区高度, 切页和错误提示变化保持窗口顶边固定. 首次入门提供双面片 Logo 动画, 快捷键区域复用偏好页的录制 popover. 全局触发使用 Carbon 注册, 录制使用 NSEvent 本地监听, 均免辅助功能权限

欢迎页可见时, 快捷键触发与成功录制使用 Logo 图片创建真实贴图, 同一会话复用已有演示贴图, 隐藏后再次显示, 删除后重新创建. 演示沿用会话持久化, 剪贴板保持原内容. 欢迎页关闭后快捷键恢复普通贴屏行为

Vortex 1.0.4 在当前屏幕四角生成短时烟花. 透明非激活面板保持点击穿透, 3.2 秒后释放 SwiftUI TimelineView. 关闭欢迎页、退出、屏幕拓扑变化或开启减少动态效果时结束烟花

签名与公证在构建完成后执行, GitHub Pages 承载官网, GitHub Releases 承载可下载应用

Puv 自有代码采用基于 MIT 授权范围的 Puv Source License 1.0, 限制第三方在应用商店分发同类应用, 作者保留官方发行权. 此许可属于源码可用许可, 第三方 MIT 与 Apache 组件分别遵循原许可

构建入口 scripts/swift.sh 同时传递编译 SDK 与 Clang 链接驱动的 isysroot. Mach-O 的 minos 保持 macOS 13, SDK 记录当前工具链版本. scripts/check-build-sdk.py 核对各架构 SDK, 原生控件外观遵循系统对该 SDK 的行为

热键行采用 140 × 28 pt 原生录制容器, 内部按修饰键 + 普通键显示 20 pt 高键帽, 上、下、左内边距均为 4 pt, 右侧保留延展空间. 清除按钮为 28 × 28 pt, 间距 4 pt. 清除操作解除注册并持久化 hotKeyEnabled=false, 成功录制后恢复绑定; 注册失败保留当前启用状态

录制中的 Carbon 事件转交 KeyRecorder, 相同有效绑定显示蓝色反馈, 新绑定显示绿色反馈, 注册失败显示红色反馈. 录制反馈期间全局贴图触发保持抑制

再次贴上使用 LivePin 保留的原始图像或文本创建独立 ID、窗口与持久化资产. 隐藏原贴图继续保持隐藏, 新贴图正常显示. 贴图数量与内存限制沿用新建路径

文本最小高度为 54 pt, 图像最小高度为 80 pt. 自然尺寸、复原与边缘缩放共享各自的最小尺寸, 原文换行保持原样. 缩放跟踪期间固定方向光标, 结束后恢复光标区域

关于页提供主页、Github、欢迎使用 Puv、许可证与喂胖大咪. 单色 Logo 插图放大并局部裁切, 边缘渐隐, 插图区域与按钮区保留 14 pt 间隔. 捐赠弹窗使用 Mos 的作者收款资源与外链, 视图实现为 Swift AppKit, 普通背景、705 × 691 pt 布局与原生 transient popover 对齐 Mos

偏好容器的 frame 与 bounds 跟随实际窗口. NSTabViewController 在窗口动画开始前提出的页面尺寸只作用于页内容, 毛玻璃背景按所有页面的最大高度预留覆盖范围. 切页回归检查窗口动画中间帧、固定顶部和快速连续切页

热键帮助弹层列出支持的剪贴板图片与文本内容. 空贴图列表显示模板矢量手绘插图, 清空全部操作仅在列表存在内容时出现
