# Pir 架构

本文面向开发者与后续 agent

## 组件

| 边界 | 职责 |
| --- | --- |
| App 生命周期 | 正式与调试启动策略、首次欢迎、菜单栏入口、应用重新打开与退出 |
| 剪贴板读取 | 按触发时内容选择文件 URL、图像或文本, 保留文本换行与空白 |
| 面板管理 | 创建独立 NSPanel, 定位、缩放、复原、隐藏、最小尺寸与关闭释放 |
| 会话存储 | 原子元数据写入、内容资产、后台 I/O、关闭删除与退出刷新 |
| 屏幕定位 | 稳定屏幕 UUID、屏幕内相对坐标、断开临时迁移与重连恢复 |
| 快捷键 | Mos 来源录制交互、全局系统注册、冲突处理与偏好持久化 |
| 偏好设置 | 基础设置、贴屏管理、更新与关于, ServiceManagement 开机启动状态同步 |
| 首次入门 | Logo 动画、窗口内快捷键录制、Logo 贴屏试用与 Vortex 屏幕烟花 |
| 文件操作 | NSCollectionView 选择、公开文件系统操作、跨浮窗引用同步与原生文件简介 |
| PirCore | 内容分类、尺寸约束与快捷键等可独立测试的策略 |
| 官网 | 静态产品页、shader 视觉与 GitHub Release 下载 |

## 设计决策

原生 AppKit 提供菜单栏、非激活面板与动态系统颜色, SwiftPM 提供轻量构建和核心行为测试. 系统注册的快捷键直接驱动单次剪贴板读取, 应用空闲时保持事件驱动

每张贴图拥有独立窗口与内容生命周期, 管理页与浮窗关闭采用相同删除路径. 管理页提供隐藏与显示, 会话保存隐藏状态. 清空全部操作在确认后关闭所有可见和隐藏贴图, 并清理保存记录. 图片缩略图使用系统分隔线颜色描边. 悬停工具条提供内容复制、原始尺寸复原与关闭, 边缘 6.5 pt 区域响应缩放并显示对应方向光标. 用户关闭后清理记录并释放图像和文本. 应用退出保留会话, 重启后恢复. 图片采用 cover 裁剪填满面板, 初始尺寸保留原始图片的逻辑显示尺寸. 文本保留原有换行与缩进, 使用系统背景色与文字色适应明暗主题

会话内容位于 `~/.config/pir/`, 创建贴图时写入内容, 移动与缩放仅更新元数据并合并后台写入. 屏幕归属使用稳定显示器 UUID, 保存屏幕内位置, 临时迁移保留原始归属供重连恢复. 原生移动通知参与位置保存, 退出刷新补采待结束的用户移动; 屏幕拓扑协调通过独立程序定位入口更新展示位置. 恢复和临时迁移采用对应内容类型的最小尺寸

文本使用系统 TextKit 2 视口布局, 显式解除默认最小宽度限制, 频繁缩放遵循可见内容布局, 规避全文重复排版

图片创建时从已解析的 CGImage 检查四条 1 px 外沿, alpha 小于 254 时关闭 NSWindow.hasShadow, 表面圆角设为 0. 检查采用边缘条带, 临时空间随边长增长, 缩放期间复用创建时的结果. 原图透明度与自带阴影保持原样, 不透明图片与文本继续使用系统窗口阴影和 10 pt 圆角

浮窗悬停工具条使用白色图标并锚定左上角. 普通内容采用窗内工具条, 径向暗色渐变覆盖 140 × 64 pt 范围; 透明图片采用 104 × 40 pt 独立非激活子面板, 位于图像上方, 屏幕顶部空间不足时改用下方. 渐变背景采用 10 pt 圆角和裁切, 装饰视图保持点击穿透. 按钮按下时图标围绕中心放大至 116%, 松开后恢复, 点击区域与布局保持原有尺寸

普通内容工具条采用 0.18 秒透明度过渡. 透明图片工具条与虚线轮廓同时采用 92% 至 100% 缩放和透明度过渡, 退出采用反向过渡; 减少动态效果时直接切换状态. 动画按当前呈现值衔接快速进出, 延迟回调核对悬停代次. 图像与子面板之间保留短暂离场宽限, 子面板在关闭时解除父子关系并释放

透明图片的输入环使用 CAShapeLayer 的 evenOdd 填充, 覆盖四边 6.5 pt 并保留内部区域. 环的 alpha 为 1/255, WindowServer 通过该低透明度边缘接收缩放输入; AppKit 命中区域与光标区域使用相同边界. 悬停虚线使用独立无阴影层并保持点击穿透

文件浮窗仅显示复原和关闭按钮, 图片与文本保留高度为 13 pt 的复制图标. 文件图标采用 56 pt 尺寸, 固定网格间距为 8 pt, 余量留在行末. PinFileSizing 按文件数量、视图模式和可用屏幕计算新建与复原尺寸; 单行图标窗口高度为 152 pt, 单行列表高度为 90 pt. 切换视图与移除引用后重新适配高度, 手动缩放及会话恢复采用保存尺寸

文本与文件浮窗的底层复用 PreferencesStyle 的 NSVisualEffectView, 材质为 toolTip, 混合模式为 behindWindow. 滚动视图、裁剪视图与文本视图使用透明背景, 文本颜色跟随系统外观

新建文本窗口采用 CoreText 测量自然尺寸, 最小 120 × 54 pt, 最大 560 × 420 pt, 同时限制为屏幕可用尺寸的 55% × 60%. 测量最多检查 4097 个 UTF-16 单元, 超过 4096 单元时直接使用尺寸上限. 正文保留完整内容并竖向滚动, 会话恢复优先使用已保存窗口尺寸

AppLaunchPolicy 区分正式、debug、登录与首次启动. 正式版完成欢迎后的常规启动保持静默, debug 本地调试展示偏好设置, 首次非登录启动展示欢迎页, 登录启动保持静默. 隐藏菜单图标后的显式启动和应用重新打开事件恢复偏好设置入口. 开机启动状态以 SMAppService 当前状态为准, 注册失败时界面显示实际状态

偏好设置集中在 Sources/Pir/Preferences/, PreferencesStyle 定义公共字体、间距、页高与材质. NSTabViewController 的 toolbar 模式生成系统页签和选中态. 基础与关于使用 AppKit, 贴屏列表嵌入 SwiftUI. 各页继承公共 toolTip 毛玻璃根视图, 窗口采用 fullSizeContentView, 背景覆盖整窗与所有页面的最大动画范围, 页面固定高度并锚定顶部安全区域. 页面顶边锚定容器顶部, 窗口尺寸采用 AppKit 实测装饰区高度, 切页和错误提示变化保持窗口顶边固定. 首次入门提供双面片 Logo 动画, 快捷键区域复用偏好页的录制 popover. 全局触发使用 Carbon 注册, 录制使用 NSEvent 本地监听, 均免辅助功能权限

欢迎页可见时, 快捷键触发与成功录制使用 Logo 图片创建真实贴图, 同一会话复用已有演示贴图, 隐藏后再次显示, 删除后重新创建. 演示沿用会话持久化, 剪贴板保持原内容. 欢迎页关闭后快捷键恢复普通贴屏行为

欢迎窗口每次展示按当前屏幕 visibleFrame 的几何中心定位. 开始按钮使用原生 borderedProminent 和 large 控件规格, 标签最小尺寸为 168 × 28 pt, 外围包含原生按钮留白

Vortex 1.0.4 在当前屏幕四个区域分别随机采样发射位置, 发射方向朝向屏幕中心. 粒子模板尺寸为 84 pt, 爆炸初始速度为 0.54、速度变化量为 0.42, 分别为此前参数的三倍. 透明非激活面板保持点击穿透, 最后触发后 3.2 秒释放 SwiftUI TimelineView. 关闭欢迎页、退出、屏幕拓扑变化或开启减少动态效果时结束烟花

签名与公证在构建完成后执行, GitHub Pages 承载官网, GitHub Releases 承载可下载应用

Pir 自有代码采用基于 MIT 授权范围的 Pir Source License 1.0, 限制第三方在应用商店分发同类应用, 作者保留官方发行权. 此许可属于源码可用许可, 第三方 MIT 与 Apache 组件分别遵循原许可

构建入口 scripts/swift.sh 同时传递编译 SDK 与 Clang 链接驱动的 isysroot. Mach-O 的 minos 保持 macOS 13, SDK 记录当前工具链版本. scripts/check-build-sdk.py 核对各架构 SDK, 原生控件外观遵循系统对该 SDK 的行为

默认全局快捷键为 Shift + Command + V, SettingsStore 继续读取用户显式保存的绑定. 热键行采用 140 × 28 pt 原生录制容器, 内部按修饰键 + 普通键显示 20 pt 高键帽, 上、下、左内边距均为 4 pt, 右侧保留延展空间. 清除按钮为 28 × 28 pt, 间距 4 pt. 清除操作解除注册并持久化 hotKeyEnabled=false, 成功录制后恢复绑定; 注册失败保留当前启用状态

录制中的 Carbon 事件转交 KeyRecorder, 相同有效绑定显示蓝色反馈, 新绑定显示绿色反馈, 注册失败显示红色反馈. 录制反馈期间全局贴图触发保持抑制

再次贴上使用 LivePin 保留的原始图像或文本创建独立 ID、窗口与持久化资产. 隐藏原贴图继续保持隐藏, 新贴图正常显示. 贴图数量与内存限制沿用新建路径

文本最小高度为 54 pt, 图像最小高度为 80 pt. 自然尺寸、复原与边缘缩放共享各自的最小尺寸, 原文换行保持原样. 缩放跟踪期间固定方向光标, 结束后恢复光标区域

关于页提供主页、Github、欢迎使用 Pir、许可证与喂胖大咪. 单色 Logo 插图放大并局部裁切, 边缘渐隐, 插图区域与按钮区保留 14 pt 间隔. 捐赠弹窗使用 Mos 的作者收款资源与外链, 视图实现为 Swift AppKit, 普通背景、705 × 691 pt 布局与原生 transient popover 对齐 Mos

偏好容器的 frame 与 bounds 跟随实际窗口. NSTabViewController 在窗口动画开始前提出的页面尺寸只作用于页内容, 毛玻璃背景按所有页面的最大高度预留覆盖范围. 切页回归检查窗口动画中间帧、固定顶部和快速连续切页

热键帮助使用 16 pt 的 mini 问号按钮, 弹层列出支持的图片、文本与文件内容. 贴屏页使用双方框页签图标, 空列表显示文字、图片与文件卡片组合的模板矢量线稿, 清空全部操作仅在列表存在内容时出现

文本浮窗使用可编辑 NSTextView, 修改同步更新 LivePin 与管理页标题, 0.3 秒合并内容资产写入. 退出刷新先提交所有待写内容, 空文本记录保持可恢复. 顶部 12 pt 留白与 Option 拖动正文提供窗口移动, 边缘 6.5 pt 继续负责缩放

文件浮窗使用 NSCollectionView 和 NSWorkspace, 保存 FilePinContent 中的文件 URL 列表与布局模式. ClipboardReader 优先识别 file URL, 随后识别图片与文本. 原生 NSURL pasteboard writer 提供外部文件拖拽. 空白区域拖动使用相交框选, Command 对相交项执行选择切换, Shift 追加相交项. 图标选中态采用图标描边与文件名背景, 列表选中态采用整行系统高亮

文件菜单提供打开、移到废纸篓、显示简介、重命名、在 Finder 中显示和从列表移除. FilePinActions 使用 FileManager 完成两阶段临时路径重命名, 提前检查目标冲突, 批量名称追加编号并保留文件扩展名; 失败恢复原路径, 恢复未完成项记录实际位置. 模态重命名以捕获的 URL 标识操作对象. NSWorkspace.recycle 的结果按实际成功路径更新引用, 失败项继续保留

FilePinReferenceChange 广播重命名和废纸篓结果, 各文件浮窗同步直接引用及目录后代引用, 内容变更沿用会话写入路径. 从列表移除仅更新引用, 最后一项移除沿用浮窗关闭路径

FileInfoWindowController 使用公开 URL resourceValues、FileManager 属性与 NSWorkspace 图标提供本应用原生简介窗口. 字段包含名称、种类、大小、位置、创建时间、修改时间、读写状态、POSIX 权限、拥有者与群组, 支持文本选择与复制. 每个 URL 对应独立窗口, 文件视图持有控制器直至关闭; 目录大小显示未统计状态

欢迎页快捷键外框按键帽自然尺寸加四边 8 pt 留白, 连续试用使用单一屏幕面板叠加烟花, 最多保留四组粒子系统

应用文案使用 en.lproj 与 zh-Hans.lproj 的 Localizable.strings, NSLocalizedString 从模块资源包读取, 语言选择遵循系统与每应用语言设置. scripts/check-localizations.py 检查双语键集合、重复键、空值与静态查找覆盖. 官网使用按键组织的双语 JSON, 默认选择浏览器语言并保存用户切换结果
