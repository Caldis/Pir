# Pir v0.1.0 实施计划

读者为开发者与执行 agent, 本次用户已授权直接实施、调用子代理并完成发布闭环

## 目标

交付原生 macOS 应用、Shader Art 应用与菜单图标、GitHub Pages 官网、可维护的 agent harness, 并完成 Developer ID 签名与 Apple 公证

## 并行职责

| 执行者 | 文件范围 | 交付与验证 |
| --- | --- | --- |
| native_app | Sources、Tests、Package.swift、Resources | 应用功能、Mos 热键复用、Swift 测试与构建 |
| brand_website | website、assets | 图标、官网、shader 库探索、静态与浏览器检查 |
| 主 agent | scripts、.github、.agents、docs、发布集成 | 构建、公证、集成验收、GitHub Release 与 Pages |

## 执行顺序

1. 审计 Mos、目标目录、GitHub 身份与签名环境
2. 核心行为先建立有意义的失败测试, 再实现与验证
3. 实现 AppKit 应用与设置, 完成图片和文本贴屏
4. 探索 shader-effects-inc/shaders, 完成原创图标与官网
5. 合并共享目录内独立产物, 检查需求与实际代码, 进行一次独立代码审查
6. 运行单测、Universal 构建与 UI 交互验收
7. Developer ID 签名、公证、装订、Gatekeeper 验证与镜像打包
8. 发布源代码、Release 与 Pages, 回读下载、哈希及线上站点状态
