## 设计决策

全部图片工具条采用均匀半透明深色圆角背景, 透明图片继续采用外置子面板, 文本与文件采用窗内径向渐变. 普通图片 fit 留白时显示虚线, 模式与窗口比例变化同步更新边界. 虚线采用紧贴轮廓的暗色衬底和短距离柔化, 保留原有淡入缩放与图片透明区域

Apple 的 NSTrackingArea 文档说明 activeAlways 与 cursorUpdate 同用时, cursorUpdate 消息保持停用. 原实现使用该组合. 本轮分离始终活跃的悬停跟踪与应用活跃时的光标跟踪, 进入和移动事件同步应用对应边缘光标. 事件路径和实际 NSCursor 状态分别提供验证, 几何计算结果只证明策略值

浮窗子代理负责共享源码内的三项修改, 文档采用独立文件并行更新. 主 agent 统一构建、交互与发行, 重型进程并发上限为 3

参考资料: [Apple NSTrackingArea activeAlways](https://developer.apple.com/documentation/appkit/nstrackingarea/options-swift.struct/activealways)

## 实施与验证

- 全部图片工具条采用 alpha 0.5、10 pt 圆角和 116 × 40 pt 背景; 文本与文件沿用径向背景
- fit 留白图片的虚线随模式、窗口比例与悬停状态更新
- 白色虚线采用紧贴暗线和短距离柔化, 固定 6.5 pt 遮罩保留内部透明; 零锚点内容层的缩放每侧最多内缩 2 pt
- 光标采用独立 tracking area、进入与移动事件更新及手势内方向锁定
- 119 项 Swift 测试、5 项 Python 发布工具测试、双语、网站及脚本检查通过; Universal 构建通过, 两个架构的最低系统为 macOS 13、链接 SDK 为 27
- 两次只读审查完成; 首次发现的大窗口动画裁切已修复, 新增实际动画 transform 的起点、中点与终点像素回归, 补充需求的聚焦审查未发现实质问题
- 本机应用恢复透明图片、fit 图片与隐藏文本, 管理页显示三条记录和对应隐藏状态

Limited Review: 桌面自动化对非激活浮窗的 hover 与拖动支持有限, 本轮鼠标操作未取得确定的缩放完成证据. 白底与深底虚线、中间帧边缘可见性、工具条底色、fit 状态切换和 NSCursor 事件路径采用定向测试证据; 完整实际悬停观感与失活应用鼠标投递仍属有限人工覆盖


## 图片模式过渡设计决策

#17 与 #16 共用图片显示模块, 两项合入 0.1.6. 图片独立图层以 bounds 与 position 表达 cover / fit 的显示区域, 裁剪容器保留窗口边界, 尺寸动画读取 presentation 当前值衔接重复操作. 窗口尺寸与复制源图保持原值, 减少动态效果直接更新几何

参考资料: [Apple CALayer presentation](https://developer.apple.com/documentation/quartzcore/calayer/presentation()), [Apple contentsGravity](https://developer.apple.com/documentation/quartzcore/calayer/contentsgravity)


#17 的图片几何过渡和 presentation 中断接续通过定向回归与只读审查. 中间帧保持等比、居中与原始 bitmap, 原图复制和会话模式恢复回归通过. 最终完整检查包含 119 项 Swift 测试与 5 项 Python 发布工具测试
